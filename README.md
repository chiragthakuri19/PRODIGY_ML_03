# PRODIGY_ML_03: Image Classification using SVM

This repository implements a **Support Vector Machine (SVM)** to classify image data into two classes (Cats vs Dogs).

## Dataset
- Kaggle Dogs vs Cats Dataset (Feature embeddings / visual descriptors)

## Model Details
- **Algorithm**: Support Vector Classifier (`SVC`) with RBF Kernel
- **Features**: Extracted high-dimensional visual feature representations
- **Metrics**: Accuracy, Precision, Recall, and F1-Score
